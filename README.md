# useful-prompts
collection of prompts I think could be useful for somebody else

## Available Prompts

- [SETUP_PROMPT.md](./SETUP_PROMPT.md) - Use this to set up shared AI agent guidelines (`.ai/guidelines.md`, `.ai/conventions.md`, `.ai/agent-workflow.md`) and pointer files for various AI agents in a new repository. Uses a multi-file structure to prevent guidelines bloat.
- [BMAD_FRAMEWORK_PROMPT.md](./BMAD_FRAMEWORK_PROMPT.md) - Use this to set up a BMAD-lite documentation framework (PRD, architecture, epics, personas) under `.ai/`. Recommended to run after `SETUP_PROMPT.md`.
- [SECURITY_AUDIT_PROMPT.md](./SECURITY_AUDIT_PROMPT.md) - A 4-phase security system: audit the codebase, triage findings with the team, fix issues using TDD, and embed security rules into project guidelines. Technology-agnostic — works with any stack.
- [BUILD_MARKETING_SYSTEM_PROMPT.md](./BUILD_MARKETING_SYSTEM_PROMPT.md) - A meta-prompt that builds a complete agent-operated marketing system for any website. Give it a domain — it researches your site, competitors, and audience, then generates 12-15 executable strategy files with ready-to-run prompts. Re-run to enrich and improve. Works with any AI agent.
